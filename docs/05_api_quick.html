인증 (F-AUTH)

01
POST
/v1/auth/signup
회원가입 + 면책 동의 한 번에. 5/hour/IP
02
POST
/v1/auth/login
이메일·비번 로그인 → access+refresh 토큰 한 쌍. 10/min/IP
03
POST
/v1/auth/refresh
refresh 토큰 회전 — 옛 토큰 무효화 + 새 한 쌍 발급. 60/min/IP
04
POST
/v1/auth/logout
refresh 토큰 revoke (서버측 무력화)

마이페이지 (F-ME)

05
GET
/v1/me 인증
현재 로그인 사용자 프로필 + 면책 동의 이력
06
PATCH
/v1/me 인증
이름·비밀번호 부분 갱신. 20/min/IP (argon2 비용)
07
DELETE
/v1/me 인증
탈퇴 — 하이브리드 soft-delete + email 익명화 + refresh 전체 revoke. 5/hour/IP
08
POST
/v1/me/disclaimer-ack 인증
면책 추가 동의 기록 (IP·UA 저장). 30/min/IP

09
GET
/v1/me/watchlist?limit=&sort= 인증
내 워치리스트. sort = created_at_desc | created_at_asc | risk_high | risk_low
10
POST
/v1/me/watchlist 인증
종목 추가. 중복 409 / 한도 100 초과 422. 60/min/IP
11
DELETE
/v1/me/watchlist/{ticker} 인증
종목 제거 (멱등). 60/min/IP

종목 마스터 (F-TICKERS)

12
GET
/v1/tickers
활성 종목 전체. 메타 (사명·sector·시총·통화)
13
GET
/v1/tickers/search?q=
자동완성. ticker prefix → 영문명 → 한글명 우선순위
14
POST
/v1/tickers/sync/{target} 운영
target=all → 시드 50종목 메타 동기화 / 단일 ticker → 1개만. yfinance UPSERT

가격 (F-PRICES)

15
GET
/v1/prices/{target}
최신 1일 OHLCV. target=all 또는 단일 ticker. yfinance fetch + UPSERT
16
POST
/v1/prices/sync-history/{target}?period=1y 운영
OHLCV 히스토리 일괄 적재. period = 1mo / 3mo / 6mo / 1y / 2y / 5y / max

거시지표 (F-MACRO)

17
GET
/v1/macro/{code}
단일 시리즈 조회 (VIXCLS · DGS10 · UNRATE 등). 날짜별 시계열
18
POST
/v1/macro/sync/{target}?lookback_days=400 운영
FRED → DB 동기화. target=all 또는 단일 code

21
POST

22
POST
/v1/risk/sync/baseline 운영
레거시 — CSV 파일 경로로 적재
23
GET
/v1/risk/spotlight?scope=all|watchlist 선택

24
