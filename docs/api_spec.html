BEFORE API 명세서

v1 endpoint 일람과 요청/응답 JSON 예시. 모든 응답은 공통 envelope (data / meta) 로 감싸지며, 에러는 error envelope 로 반환된다.

Base URL · https://api.before.app 버전 · v1 (prefix: /v1) 인증 · Bearer JWT (HS256) Content-Type · application/json

DOC응답 envelope · 인증

모든 응답은 다음 두 가지 envelope 중 하나다.

성공 envelope

200 OKapplication/json
{ "data": { // endpoint 별 응답 페이로드 }, "meta": { "request_id": "req_8a3f2e919c5b4d72a3e1", "ts": "2026-05-15T12:34:56Z", "next_cursor": null } }

에러 envelope

4xx · 5xxapplication/json
{ "error": { "code": "TICKER_NOT_FOUND", "message": "해당 종목을 찾을 수 없습니다.", "details": { "ticker": "ZZZZ" } }, "meta": { "request_id": "req_a2c1...", "ts": "2026-05-15T12:34:56Z" } }

인증 (Bearer)

로그인 후 받은 access_token 을 모든 인증 필요 요청의 헤더에 포함한다.

Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

토큰이 만료되면 401 TOKEN_EXPIRED 가 떨어진다. 이때 refresh_token 으로 POST /v1/auth/refresh 호출해 새 페어를 받는다 (회전 방식 — 옛 refresh 는 revoke).

codestatus설명
